# 교육의 경제학 6조 · 웹 발표 자료

`교육의 경제학 6조.pptx`를 웹으로 옮긴 발표 자료예요. 결과 슬라이드(15–19번)는 구글 폼 응답 시트를 5초마다 읽어 채점하고, 그래프와 표를 바로 다시 그려요.

## 실행

```bash
npm install
npm run dev
```

배포용 빌드는 `npm run build`이고, 결과물은 `dist/`에 생겨요. 정적 파일이라 Vercel, Netlify, GitHub Pages 어디에 올려도 돼요.

## 발표 중 조작

| 키 | 동작 |
| --- | --- |
| → / ← (또는 클릭) | 다음 / 이전 슬라이드 |
| 숫자 + Enter | 해당 번호로 이동 (예: `15` Enter) |
| F | 전체화면 |
| Space (10·12번) | 타이머 일시정지 / 다시 시작 (슬라이드에 들어오면 자동 시작) |
| R (10·12번) | 타이머 처음으로 (멈춘 상태로 대기) |
| D | 결과 데이터 창 |

10번 타이머는 마지막 1분이 되면 안내 문구가 "지금 혼자 풀면 얼마나 잘 풀 것 같나요?"로 바뀌어요. 끝나면 숫자가 파란색 00:00으로 바뀌어요.

## 결과 데이터

D를 눌러 데이터 창을 열어요.

- **구글 시트**: 기본값이에요. 시트가 "링크가 있는 모든 사용자 보기"로 공유되어 있어야 해요.
- **CSV 파일**: 와이파이가 안 될 때 써요. 시트에서 *파일 → 다운로드 → CSV*로 받은 파일을 화면에 끌어다 놓으면 돼요.
- **샘플 데이터**: 리허설용 가짜 응답이에요.
- **집계 시작 시각**: 이 시각 이전 응답은 집계에서 빼요. 테스트 제출을 거를 때 써요.

마지막으로 읽은 데이터는 브라우저에 저장돼서, 새로고침하거나 네트워크가 끊겨도 남아 있어요.

### 채점 규칙

정답은 `src/data/answerKey.ts`에 있어요. `최종본.pdf`의 진행자용 정답(9–10쪽)을 옮긴 거예요. 칸 하나가 1점이고, 7·8·11·12번은 두 칸이라 2점이에요.

- **금액**: 만 원 단위로 비교해요. `200`, `200만 원`, `2,000,000`, `2000000원`을 모두 200으로 읽고, `없음`은 0으로 읽어요.
- **객관식**: `2`와 `②`를 같은 답으로 봐요.
- **7번 (2)**: `아니오`가 정답이에요.
- **완전 정답률(16번 슬라이드)**: 그 문항의 모든 칸을 맞힌 경우만 정답으로 세요.

열은 순서가 아니라 제목("7번 (1)" 등)으로 찾아요. 그래서 폼 문항 순서가 바뀌어도 괜찮아요.

> **주의:** 구글의 CSV 내보내기(`gviz`)는 열마다 숫자인지 글자인지 다수결로 정해요. 그래서 숫자 열에 "16만원" 같은 글자 답이 섞이면 그 칸을 빈칸으로 보내요. 응답 시트에서 답안 열(D열부터 끝까지)을 선택하고 *서식 → 숫자 → 일반 텍스트*로 바꿔 두면 이런 일이 없어요.

## 슬라이드 다시 변환하기

PPT를 고치면 아래 명령으로 다시 변환해요.

```bash
python3 scripts/pptx_to_json.py "<경로>/교육의 경제학 6조.pptx" src/deck/slides.json public/media
```

변환하면 도형 위치, 글꼴 크기, 색이 PPT와 같은 1920×1080 좌표로 `src/deck/slides.json`에 저장돼요. 타이머, 점 그래프, 결과 표는 도형 이름으로 찾아 실시간 값으로 바꿔 끼워요(`src/live/overrides.tsx`). 그래서 PPT에서 이 도형들의 이름은 바꾸지 마세요.
